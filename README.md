# GenAI-XEnergy-Roadmap-Analysis
This repository contains the supplementary  data and framework visualizations for the manuscript: 
**"Energy-Efficient GPU Resource Management for Generative AI on HPC Systems: A Roadmap Towards Cross-Layer Co-Design Approaches"** submitted to the *Journal of Supercomputing*.

## 📌 Overview
This dataset provides a comprehensive systematic analysis of 46 primary studies focusing on energy-efficient resource management for Generative AI workloads. It includes technical taxonomy matrices and high-resolution visualizations of the proposed GenAI-XEnergy framework.

## 📂 Repository Structure

### 1. Literature Analysis Dataset
The file `GenAI-XEnergy_Literature_Analysis_Dataset.xlsx` contains two primary data sheets:
* **Bibliometric_Index**: Metadata of the 46 surveyed studies (Quartiles, Publishers, Venues, etc.).
* **Technical_Taxonomy_Matrix**: Technical extraction of research methodologies, energy reduction strategies, hardware metrics, and study limitations etc.

### 2. Survey Visualizations
The folder `/Survey_Visualizations` contains high-resolution figures (Figs 1-6) as presented in the manuscript, covering:
* Statistical distributions of workload phases and types.
* Taxonomy of decision types and energy-efficiency techniques.
* The original conceptual and architectural diagrams for the **GenAI-XEnergy** framework.
